# MediaMix Console

퍼포먼스 마케터를 위한 미디어믹스 자동 설계 툴.
타겟(맘/1인가구/직장인/시니어/10대) · 캠페인 목적(런칭/전환/리텐션) · 판매 채널(자사몰/네이버스토어) · 예산을
입력하면 조건에 맞는 매체 리스트와 예상 노출·클릭·CTR·CPC, 예산 배분안을 자동으로 계산해 보여줍니다.

## 주요 기능

- 타겟 × 목적 × 채널 조합에 따른 매체 자동 추천 (약 50개 매체 DB 내장)
- 예산 규모에 따라 추천 매체 개수 자동 조절 (핵심 4대 매체는 항상 포함)
- 매체별 최소 집행단가 배수로 예산 배분 (1원 단위 엔빵 방지)
- 배분 예산 직접 수정 가능, 수정 시 노출/클릭 실시간 재계산
- 실제 집행 리포트(xlsx) 업로드 → 실측 CTR/CPC 데이터 누적 학습
- 결과를 엑셀 파일로 다운로드

## 기술 스택

순수 HTML / CSS / JavaScript (프레임워크 없음, 빌드 과정 없음).
엑셀 처리는 [SheetJS](https://sheetjs.com)를 CDN으로 불러와 사용합니다.
서버·데이터베이스 없이 브라우저에서 모든 계산이 이루어집니다.

## 로컬에서 열어보기

`index.html` 파일을 브라우저로 그냥 열면 바로 실행됩니다. 별도 설치나 빌드가 필요 없습니다.

## 배포

정적 파일 하나로 이루어져 있어 Vercel / Netlify / GitHub Pages 등 어디에든 별도 설정 없이 배포할 수 있습니다.
